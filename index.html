05 / DIGITAL LOGIC REFERENCE

Logic reference

Use this reference to connect each CHSE circuit to the message-protection workflow.

⊕
TRANSFORMATION ENGINE

XOR gate

Outputs 1 only when inputs differ. CipherLock applies eight Boolean XOR gates to every byte.

ABY = A XOR B000011101110
Y = (A AND NOT B) OR (NOT A AND B)
MUX
INPUT SELECTION

2:1 multiplexer

Selects the plaintext for encryption or ciphertext for decryption before the shared XOR bank.

SOutput0A1B
Y = (NOT S AND A) OR (S AND B)
DMX
OUTPUT ROUTING

1:2 demultiplexer

Routes the transformed bit to the ciphertext buffer during encryption or recovered plaintext during decryption.

SY0Y10D010D
Y0 = D AND NOT S / Y1 = D AND S
8:3
EVENT ENCODING

Encoder and decoder

One active event input is encoded into a three-bit code, then decoded back to one active output.

I0 / O0000I1 / O1001I2 / O2010I3 / O3011I4 / O4100I5 / O5101I6 / O6110I7 / O7111
P
INTEGRITY CHECK

Even parity generator and checker

The parity bit is the XOR reduction of all eight ciphertext bits. A matching transmitted and recalculated bit indicates that no odd number of bit changes was detected in that byte.

P = b7 XOR b6 XOR b5 XOR b4 XOR b3 XOR b2 XOR b1 XOR b0Limit: two flipped bits can cancel and pass simple parity. Parity detects accidental changes; it does not authenticate a sender or provide cryptographic security.
06 / PROJECT NOTES

Security is a process,
not a decoration.

CipherLock makes the relationship between computer hardware fundamentals and cybersecurity visible. The interface is only a window into the actual Boolean operations underneath.

CHSE FOUNDATION

Hardware concepts

XOR gates transform the data. A multiplexer selects the direction of the shared processing engine. A demultiplexer routes the output. The encoder and decoder convert security events into signals that can be monitored.

CYS CONTEXT

Security concepts

The application demonstrates confidentiality concepts through a repeating-key XOR, integrity monitoring through parity, and event observability through a one-hot security event circuit.

LIMITATION

Know what this is not

This is an academic circuit demonstration. Repeating-key XOR and parity are not modern encryption or authentication. Never use CipherLock to protect real secrets.
